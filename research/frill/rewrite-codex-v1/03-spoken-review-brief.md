# Frill spoken review brief

Frill is a clean place for customers to submit ideas, vote, see a roadmap, and hear when something ships. It is useful when one person will keep that loop moving every week.

The test is messy feedback, not a blank board. Import close copies, merge them, check votes and followers, then undo a wrong merge. Test private and anonymous users too.

I would choose Frill for a small product team that does not need a full helpdesk. I would skip it when nobody owns moderation or when private feedback forces a plan that costs too much.
