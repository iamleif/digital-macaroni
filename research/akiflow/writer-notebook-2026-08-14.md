# Akiflow writer's notebook

## Research scope

- Research-based review; no product test
- Price, integrations, inbox, mobile guide, and recent fixes checked 2026-08-14
- Review counts: G2 96, Capterra 106, Trustpilot 215, Product Hunt 18, Reddit 20 sampled voices
- The prior evidence failure was a field-name mismatch, not a lack of sources

## Reader and job

- Primary reader: a busy person whose tasks arrive in email, Slack, Todoist, Asana, or other tools and who plans each day on a calendar
- Plain example: save a Slack message as a task, see it in one inbox, then drag it into Tuesday at 10:00 for 45 minutes
- Cost of failure: a task fails to import, completion does not return to the source, or the calendar becomes an unrealistic wish list

## Product facts

- Imports from Google and Outlook calendars, email, Slack, Teams, Notion, Todoist, Microsoft To Do, Asana, Linear, Jira, GitHub, Trello, ClickUp, and more
- Imported tasks first enter an inbox and can then be dated or placed on the calendar
- Keyboard shortcuts and a command bar speed capture and planning
- Mobile supports capture, calendar planning, tasks, events, widgets, and some integration setup
- Pro is $34 monthly or $19 per month billed yearly; trial is seven days

## Experience records

### Tasks from several apps became one daily plan

- Source: dominant review and community pattern
- Action: import tasks, choose what matters, and give each one a real place on the calendar
- Result: less jumping between task lists and the calendar
- Consequence: useful for a person who already plans by time, not someone who prefers a simple checklist

### A connection or sync needed repair

- Source: reviews and recent official changelog
- Result: calendar changes, Gmail settings, or task-app links did not always save or sync as expected
- Consequence: trial completion and rescheduling in both directions before trusting imports

### Mobile did not match desktop expectations

- Source: mixed review pattern; current mobile docs show wider functions than older reports
- Result: some customers found the phone app less capable or less stable
- Consequence: test capture, reschedule, and completion from the phone with the current version

## Feature translation

### Time blocking

- What it does: reserves a real start and end time for a task on the calendar
- Main limit: an overfilled plan simply moves the backlog onto the calendar

### Universal inbox

- What it does: collects imported tasks and saved messages before the user decides when to do them
- Main limit: weak import filters can bring in noise

### Daily ritual

- What it does: asks the user to review unfinished work and build the next day
- Main limit: useful only if the person will maintain the habit

## Conflict ledger

- Akiflow can reduce app switching, but it also depends on many outside connections.
- Reviewers praise speed on desktop, while mobile and sync concerns recur.
- The price can be justified by daily use, but not by occasional planning.
