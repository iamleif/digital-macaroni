## Claims

- WeWeb visually builds the screens and browser behavior of a web app, while allowing its own backend or outside services such as Supabase, Xano, and APIs to store data and handle server work. [verified; fact; official-current-pricing, official-roadmap]
- Paid seats start at $20 monthly, pricing is per builder rather than app user, and custom domains or WeWeb hosting can add cost. [verified; fact; official-current-pricing, official-pricing-context]
- Paid plans support code export, GitHub sync, and self-hosting. [verified; fact; official-pricing-context, official-roadmap]
- Design freedom, outside backend connections, and code export are repeated strengths. [supported; reported-pattern; capterra, g2, reddit-learning]
- Databases, sign-in, permissions, changing page data, phone layouts, and debugging create a significant learning curve even when little code is typed. [supported; reported-pattern; reddit-learning, reddit-fragility, capterra]
- A detailed community account reports that WeWeb AI replaced working sign-in logic with sample data, illustrating why generated changes need review but not establishing a normal result. [limited; reported-pattern; reddit-fragility]
