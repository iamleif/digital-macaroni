# Formbricks spoken review brief

Formbricks can show a survey after someone does something inside a product. That timing is useful, but the right account must see the question once and the answer must reach the right user record.

I would start with Cloud and test repeated events, account switching, dismissal, and phones. Self-hosting means owning the database, email, backups, updates, and outages.

The core code is open, while roles, audit logs, sign-on controls, spam protection, and other company features can require Enterprise. I would choose Formbricks only after both the targeting and the license fit are clear.
