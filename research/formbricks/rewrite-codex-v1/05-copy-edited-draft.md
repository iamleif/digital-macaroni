Formbricks runs surveys through links, websites, email, and screens inside a product. A software team can ask a question after someone finishes setup, uses a new feature, or starts to cancel.

We recommend Formbricks when surveys shown inside an app or control over response data matter. The survey builder is easy to approach. Showing the question to the right person at the right moment takes more care.

Cloud is the sensible starting point for most teams. Self-hosting is a separate choice that needs a firm reason and a named owner.

## Product targeting is the strongest feature

A normal survey waits for someone to open a link. An in-product survey appears while that person is using the app. The timing adds useful context to the answer.

Formbricks can decide who sees a survey from details such as plan, language, or recent use. It can also connect the answer to a known user or pass hidden context into the response.

Wrong targeting creates bad data. A repeated event may show the question twice. A shared computer may attach an answer to the wrong account. Someone who changed their mind may still see a cancellation survey.

Use test accounts with different plans and histories. Send the same event twice, switch users, and open the app on a phone. Dismiss the survey and come back later. Check who becomes eligible again and which record receives each answer.

The builder, styling, targeting, API, and connections receive broad praise in small favorable review samples. Those strengths do not settle identity or timing. Test the real rules before showing the survey to customers.

## Cloud removes the server job

Formbricks Cloud runs the service and stores responses in its hosted setup. The pricing page said the cloud service was hosted in Frankfurt when the evidence was collected.

Self-hosting puts the software and data on servers the team controls. The team then owns the database, secure web access, email, storage, backups, monitoring, updates, and outages.

The listed server needs were modest. A small server can run the software, but those numbers say nothing about a failed update or broken email. A working admin login also does not prove that customers can open and finish a survey.

Some technical users describe self-hosting as easy, while others struggle with setup and changes. A team that already runs web services may know the work. A team trying to avoid a cloud bill can spend more staff time than the server saves.

Start with Cloud unless the company can name a data or hosting rule that requires its own server. For a private setup, restore a backup and update a test copy. Complete a real survey after each change and watch the public survey route.

## The free code has paid feature gates

The Formbricks core uses the AGPLv3 license. Its Community Edition can be self-hosted for business use with unlimited surveys, responses, and users. It supports link, website, app, and email surveys.

Some controls require the Enterprise Edition. These include team roles, customer groups, audit logs, sign-on controls, spam protection, and other advanced features. Paid options also remove branding and add more support or report tools.

Community Edition users all have admin rights. A company that needs staff to manage only certain projects requires the paid role system.

This split has frustrated some self-hosters who expected every feature in the community version. Avoid that surprise by listing each required control before setup. Check branding, roles, identity, spam, audit history, support, and private code changes against the current license table.

Get paid terms in writing when the list crosses into Enterprise. Open code is valuable, though it does not promise every company control at no charge.

## Cloud pricing jumps quickly

Cloud Hobby was free for one workspace and 250 monthly responses. It included link and in-product surveys, question logic, hidden fields, partial responses, uploads, single-use links, and API access.

Cloud Pro was $74 per month with yearly billing for 2,000 responses and three workspaces. It added unlimited seats, branding removal, known respondents, contact groups, connections, follow-up email, webhooks, mobile app kits, and AI translation.

Cloud Scale was $325 per month with yearly billing for 5,000 responses and five workspaces. It added roles, response quotas, stronger feedback tools, custom charts, two-step login, and spam protection.

The move from free to Pro is large for a small team that needs 300 responses or one paid control. Self-hosting removes the Community Edition response limit, but replaces the cloud bill with server and staff work.

Choose from the feature and response needs together. A low survey count does not help if one access rule requires a higher tier.

## The trial should prove one real survey

Formbricks is useful for a software team that wants feedback tied to product behavior. It is also worth considering when open code or private deployment is a firm need.

Skip it when a simple emailed survey link already answers the question. Large organizations with strict access and specialized reports should test the paid controls closely.

Run one survey with real rules for who sees it, whose answer is saved, and how often it appears. Make an event arrive twice, switch accounts, dismiss the question, return later, and test a phone. Check that each answer reaches the right user and report.

For your own server, match every needed feature to the license. Send email, restrict access, restore a backup, update a test copy, and watch the live survey page.

Formbricks offers strong product surveys and real deployment control. Choose it only when the targeting works and someone owns the service behind the question.
