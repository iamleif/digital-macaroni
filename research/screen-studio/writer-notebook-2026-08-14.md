# Screen Studio writer's notebook

## Reader and job

- Mac user making product demos, tutorials, release notes, or short social clips
- Record a real three-minute workflow, remove mistakes, add useful focus, export, upload, and revise it
- Failure means distracting zoom, unclear cursor, bad sound, huge file, slow correction, or an unusable format

## Product and price

- macOS only; Ventura 13.1 or later recommended
- Automatic zoom, cursor treatment, framing, editing, export, and shareable links
- $29 month to month or $9 monthly billed yearly
- Without an active plan, features remain available except video-file export

## Evidence and stance

- Fast polish is the consistent attraction
- Audio, annotation, trimming, file size, price, and Mac-only use are the limits to test
- Thesis: useful when it shortens a repeated demo workflow, unnecessary when it only adds movement
- No hands-on test

## Spoken language bank

- record the same real demo three times
- zoom only when the viewer needs help
- fix a mistake without starting over
- measure recording to final upload
- pretty motion does not make an explanation clear
