# Spoken review brief

Open with the split: Twenty cloud is a CRM buying decision, while Twenty self-hosted is also an operations decision.

Explain why teams like it: modern screens, flexible records, custom objects, APIs, inspectable code, and an active project. Then test whether it has the exact reports, mobile work, access rules, integrations, marketing tools, and workflows the buyer needs now.

For self-hosting, require a realistic backup, sequential upgrade, forced failure, restore, and rollback. Account for staff time as part of cost.

State that no installation or cloud test was run and that GitHub popularity does not prove production reliability.
