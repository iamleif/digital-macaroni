# TestSprite source packet

## Verified product facts

- TestSprite creates and runs frontend and backend tests from product documents, app behavior, and API documentation.
- Its MCP connection lets a coding assistant prepare and run a full or targeted test pass.
- Auto-Heal attempts to recover interface tests after page elements change.
- Reports can include steps, screenshots, recordings, and generated test code.
- Official pricing checked on 2026-08-25 lists Free with 150 monthly credits, Starter at $19 per month after the first month, and Standard at $69 per month.

## Reported experience

A detailed community account describes a day-first date being marked wrong because the generated check expected a month-first date. Locale configuration could correct the problem, though the author found that setting difficult to locate.

## Limits

Digital Macaroni did not run TestSprite. G2 has too few reviews to support a broad pattern, and the saved packet contains one detailed independent experience. Pricing is current, while real credit use remains unknown until a buyer tests a representative project.
