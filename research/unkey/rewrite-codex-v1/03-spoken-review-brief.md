# Spoken review brief

A few internal API keys can live as hashed rows in the main database. Unkey becomes useful when customers need separate keys, permissions, expiry, limits, instant revocation, and usage records.

Recommend it for a team selling an API or guarding several public services. Skip it while the home-built system remains one small table and a few clear checks.

Test every refusal and outage route, then model real usage charges. State that no deployment or load test was run.
