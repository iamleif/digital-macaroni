# Documenso spoken review brief

Documenso gives you an open-source way to send PDFs for a signature. You can pay for the hosted service or run it yourself. I would start hosted, even if self-hosting is the long-term goal.

First prove that one real, low-risk document works for the sender and signer. Try a phone, a wrong email address, a reminder, a decline, and the final record. The public code is a strength, but formal customer feedback is still thin.

Running it yourself means owning the database, email, certificate, backups, security, and upgrades. That is sensible when server control has real value and a named person can do the work. It is a poor way to save a subscription fee.
