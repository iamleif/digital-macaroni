# Typedream writer's notebook

- Reader: creator, founder, or small team building a landing page, portfolio, blog, or simple product site without code
- Job: build five real pages, connect a domain, make phone layouts work, collect a form, publish safely, appear correctly in search and social previews, and move the content later
- Failure: broken mobile layout, lost form, stale published page, wrong title in search, missing redirect, per-site cost surprise, or no usable export
- CMS: a structured list of repeatable content such as posts, jobs, or directory entries
- Metadata: the title, description, and image search engines and social sites use to describe a page
- Code injection: adding small script or style snippets, not owning the full site code
- Free $0; Launch $15 annual/$20 monthly; Grow $42 annual/$49 monthly; prices per site
- Thesis: excellent for a fast small site when its defaults fit; wrong when the business needs precise responsive control, deep systems, or portable code
- Decision language: build the actual five pages; test 320 pixels; submit the form ten times; break a publish; move it to a blank host
