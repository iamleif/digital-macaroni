# Encharge argument card

## Buyer

A software team that needs onboarding or retention email to react to product use.

## Decision

Choose Encharge when the team has clear event-based messages and developer help for clean event data. Skip it for a normal newsletter.

## Why

The visual canvas makes branching email paths easy to inspect. The useful software features often require Premium, and bad event data can send the wrong message or no message.

## Walk-away conditions

Leave if nobody owns the event setup, required features push the bill beyond the value, test accounts enter the wrong branch, or the sending setup remains unclear.

## Verdict

Clear email automation that depends on clean customer data.
