# Encharge spoken review brief

Encharge sends different emails based on what a customer does inside a product. The visual flow is good because a marketer can see each wait, check, and message on one page.

The flow only works when the product sends clean events. That often needs developer help. A duplicate event can send the same message twice, while a missing one sends nothing.

I would use Encharge for software onboarding with two or four clear messages. Many of the useful event features start on Premium at $159 per month. I would skip it for a normal newsletter or when nobody owns the tracking.
