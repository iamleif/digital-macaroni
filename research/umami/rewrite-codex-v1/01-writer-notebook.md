# Writer notebook

- Product: open-source website analytics available as a hosted cloud service or self-hosted app.
- Buyer: a small website or software team that wants clear traffic and event numbers with less invasive tracking.
- Strength: simple dashboard, small tracker, no cookies or visitor fingerprinting in the standard setup.

- Test: run beside the current tool, compare signups and sales with real records, then prove backup and restore if self-hosting.
